2. Modelling Data Using Distribution ¶

Visualisation 6¶

Reasoning For Visualisation 6:¶

In [86]:
# Features identified as important from boxplots and median differences
features = [
    "num_words",
    "num_stopwords",
    "num_unique_words",
    "num_spelling_errors"
]

results = []

for feature in features:

    # Non-Phishing
    non_data = df[df["label"] == 0][feature]
    non_mean = non_data.mean()
    non_var = non_data.var()

    non_r = (non_mean**2) / (non_var - non_mean)
    non_p = non_r / (non_r + non_mean)

    # Phishing
    phish_data = df[df["label"] == 1][feature]
    phish_mean = phish_data.mean()
    phish_var = phish_data.var()

    phish_r = (phish_mean**2) / (phish_var - phish_mean)
    phish_p = phish_r / (phish_r + phish_mean)

    # Phishing - Non-Phishing
    results.append([
        feature,
        phish_mean - non_mean,
        phish_var - non_var,
        phish_r - non_r,
        phish_p - non_p
    ])

# Create comparison table
nb_difference = pd.DataFrame(
    results,
    columns=[
        "Feature",
        "Mean Difference\n(Phishing - Non-Phishing)",
        "Variance Difference\n(Phishing - Non-Phishing)",
        "r Difference\n(Phishing - Non-Phishing)",
        "p Difference\n(Phishing - Non-Phishing)"
    ]
)
# Green border around the whole figure
fig = plt.gcf()
fig.patch.set_edgecolor("Green")
fig.patch.set_linewidth(4)

Answer to Research Question¶

The aim of this portfolio was to answer the question in the title. Four characteristics were identified. Based on Visualisation 5, supported by evidence throughout, the characteristics that best distinguish phishing emails from legitimate emails are:

  1. Number of Words
  2. Number of Stopwords
  3. Number of Unique Words
  4. Number of Spelling Errors

Visualisation 5 showed that these four features had the largest median differences between phishing and non-phishing emails. The median is less affected by outliers and therefore provides a more reliable representation of a typical email, compared to the mean.

The results suggest that phishing emails typically:

  • Contain fewer words
  • Contain fewer stopwords
  • Use less diverse vocabulary
  • Contain fewer spelling errors
